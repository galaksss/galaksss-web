# galaksss — websites & web apps

Отвечай по-русски. Комментарии в коде — тоже по-русски.

## Что это

Сайт-портфолио для фриланса на вайбкоде: лендинги, веб-приложения, MVP.
Задача страницы одна — чтобы основатель стартапа или студия написали на почту
или в Telegram. Язык сайта — английский, аудитория — зарубежные клиенты.

Это **не** моушен-портфолио и не его копия. Моушен-сайт лежит отдельно
(`Desktop/claude-code/portfolio-website`), его не трогаем. Отсюда запреты:
никакой рейки с таймкодом, кадров в 3D-объёме, «Mark 01», широкого капса Archivo.

## Направление (выбрано 23.10.2026, вариант A из `vibecode/directions`)

Чёрный интерфейс в духе софта для видео. **Слово «render» в текстах не используем** —
владелец: «при чём тут рендер, это стрёмно». Заголовок: «Websites, built frame by frame.»,
счётчики — «Built in 2 weeks» (OneDay сделан за **две недели** — так говорит владелец).
Прошлый вариант (индиго, стеклянная шапка, бенто, курсив Instrument Serif)
владелец назвал «по меркам 23 года» — к нему не возвращаемся.

Визуально — интерфейс программы: тонкие рамки, моно-подписи, полоски окон, HUD.

**Движение — строго на языке OneDay** (`oneday/docs/DESIGN.md`, раздел 2, и
`oneday/src/app/globals.css`): одна кривая `cubic-bezier(.16,1,.3,1)`; блок
проявляется целиком (затухание + сдвиг 28 px, 0.9–1 с, соседи шагом 90 мс);
заголовки выходят по словам из дымки (blur 10px, сдвиг .35em, 1.1 с, шаг 50 мс);
кадры сменяются кроссфейдом с размытием (blur 8px, scale .985 → 1, уход в 1.01,
0.6 с); выбор переезжает плашкой; свет под курсором — еле заметный.
**Пробовали и отвергли** (владелец: «глитчевое дерьмо, глаза режет»):
бакеты рендера — тайлы с шумом при появлении картинок, — и абстрактную
реймарчинг-скульптуру в герое («непонятное справа»). Не возвращать.

## Кейсы

- **OneDay** — главный: один день с приложением (4 шага: цели — секундомер, бассейн, видео; фокус; история — неделя столбиками с подсказкой; итоги),
  справа — живая копия OneDay в окне (`src/oneday-demo.js`, холст 960×600 с той же раскладкой,
  что `oneday/src/components/LandingHow.tsx`). Скриншоты в кейсе владелец назвал «полумёртвыми».
- **More work** — Hour, Orrin, Noctiv («Fictional brand»: бренд выдуман, дизайн и код настоящие;
  подпись «Concept by galaksss» владелец понял как «я не кодил» — не возвращать) и личные
  проекты Beatgrid, Feedcheck, Hookline («Personal project»). Ритм: широкая
  (Hour) — пара — пара — широкая (Hookline). У каждой карточки мини-окно
  с двумя кадрами (`data-a` / `data-b` на `[data-alt-frame]`): наведение
  или вкладка — второй кадр проявляется из дымки. Полоску окна строит `sections.js`.

Все шесть проектов **встроены в сайт** собранными копиями: `public/p/<имя>/` (hookline — из папки `cue`).
Карточки и витрина ведут туда (`/p/<имя>/index.html` — с `index.html`, иначе dev-сервер
отдаёт главную). Поменял проект — пересобери:
`MSYS_NO_PATHCONV=1 npx vite build --base=/p/<имя>/ --outDir ../site/public/p/<имя> --emptyOutDir`
(без переменной Git Bash портит путь base) и удали `__check.html` из результата.

Чего на странице не пишем: город и страну (только «Remote»), цены, выдуманных
клиентов и всё, что нельзя подтвердить работой.

## Палитра и шрифты

Чистый чёрный, как в софте для рендера. Тёплых цветов нет — владелец любит
синий, фиолетовый и их тёмные оттенки.

```
--bg #000 · --panel #0A0A0C     фон и панели окон
--ink / --ink-2 / --mute        текст, второй текст, подписи
--uv #8C74FF                    ультрафиолет: метки, номера, акцентные слова
--blue #5EA0FF                  синий — в свете сцены
--ok #6CF2B0                    мятный — «готово», Live
```

Шрифты: **Schibsted Grotesk** (700 для заголовков, трекинг −.05em), **JetBrains Mono** —
подписи, вкладки. Контент не шире **1240 px**, кегли умеренные (герой ≤ 66 px, секции ≤ 72 px):
прошлый вариант на 1560 px и 124 px владелец назвал «слишком широко, буквы большие, тесно».

## Структура

| Секция | Что там | JS |
|---|---|---|
| Шапка | прозрачная → тёмная после прокрутки, плашка раздела, линия прочитанного. По клику на якорь плашка сразу встаёт на цель, страница едет своей прокруткой на кривой сайта (`initAnchors`) — родной smooth-скролл владелец назвал «лагающим»: плашка цеплялась за пролетающие разделы | `motion.js` |
| Герой | заголовок «Websites, built frame by frame.» + витрина работ (OneDay, Hour, Orrin, Noctiv): автосмена 4.5 с, вкладки, наклон за курсором. Под курсором смена раз в 10 с, но не встаёт: лежащий на витрине курсор не должен её останавливать (владелец: «пусть всегда перелистывается») | `reel.js` |
| Work: OneDay | «один день с OneDay» по мотивам How it works с лендинга OneDay: шаги 9:30 AM → 10:40 PM, липкое окно с **живой копией приложения** (курсор жмёт кнопки, секундомер тикает, бассейн и видео отмечаются, столбики истории растут, карточка дня собирается; куда целиться, курсор берёт у самих кнопок), черты прогресса; на телефоне окно у каждого шага | `case.js`, `oneday-demo.js` |
| More work | шесть карточек-окон с двумя кадрами и ссылкой «Open the site» | `sections.js` |
| Services | четыре панели со схемами в стиле Wire, кривая скорости | `sections.js` |
| Process | строки queued → in progress → done, каждая — когда сама доехала до экрана (на телефоне иначе нижние успевали стать done); статус в одну строку в колонке 96 px — слово не переносится и строка не прыгает; на телефоне полоска под текстом | `sections.js` |
| About | цитата про VFX-эдиты + текст и инструменты | — |
| Contact | огромное «Have something to ship?», почта копируется | `sections.js` |

Общие кирпичи движения — в `motion.js`: `createSeg` (плашка), `createFade` (кроссфейд),
`swapText` (подпись тает и меняется), появление, свет под курсором, шапка.

## Правила

- **Контент не прячем без JS.** Начальные состояния — под `.js` на `<html>`.
- **Прячем только opacity/transform**, раскладку не анимируем.
- **rAF живёт, пока нужен**: отсчёт витрины — пока она видна и вкладка активна.
- **`prefers-reduced-motion`**: только затухание — без сдвигов, размытия, наклона и автосмены.
- **Цифры в кейсе проверены 23.10.2026**: 27.7k строк — `oneday/src/**/*.ts(x)`,
  509 тестов — `npx vitest run`, 86 коммитов — `git rev-list --count HEAD`,
  2 недели — со слов владельца. Меняются — обнови.
- Липкое окно кейса: `.case__stage` высотой в экран с `align-self:start`.

## Проверка

`public/__audit.js` — временный аудит (контраст, имена кнопок, подписи полей, цели касания,
горизонтальный скролл, заголовки): `(await import("/__audit.js")).default()` в консоли любой
страницы сайта, в том числе `/p/<имя>/`. Исключён из git.

`public/__check.html` — **временный** помощник: открывает страницу в iframe
нужного размера и прокручивает к секции (`?w=1440&h=900&at=top,work,step2,more`).
Снимать headless-Edge с `--force-prefers-reduced-motion` (видны финальные
состояния). Само движение headless не проверить — смотреть глазами. Перед деплоем удалить.

## Хостинг

**https://galaksss.pages.dev** — Cloudflare Pages, проект `galaksss`, репозиторий
`github.com/galaksss/galaksss-web`. Каждый push в `main` пересобирает сайт сам
(`npm run build` → `dist`, Node из `.node-version`). Не Vercel: бесплатный тариф там
только для некоммерческих сайтов, а реклама своих услуг — коммерция по их правилам.
